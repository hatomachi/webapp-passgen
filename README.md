# 🔐 PassGen (webapp-passgen)

> **「開いて0秒、通信ゼロ、漏洩リスクゼロ」**  
> ブラウザ内（Web Crypto API）で完結する、安心・爆速・完全オフライン対応のパスワード生成PWA。

---

## 🎯 プロダクト概要 & 開発の背景

日常的なWebサービス登録や社内アカウント設定時、パスワード生成の手間を省きつつ、セキュリティリスクを徹底排除した軽量パスワード生成ツールです。

- **ゼロ傍受リスク**: すべての生成処理は端末（Web Crypto API）で実行され、外部通信は一切行いません。
- **完全オフライン対応（PWA）**: 機内モードや通信環境が悪い場所でも即座に動作。
- **GitHub → Cloudflare Pages デプロイ**: 静的配信による高速エッジキャッシュと堅牢なSSL環境。

---

## 🛡️ セキュリティ設計仕様

1. **暗号学的に安全な乱数生成**:
   - `Math.random()` は一切使用せず、ブラウザ標準の `window.crypto.getRandomValues()` を利用。
2. **CSP（Content Security Policy）による通信物理遮断**:
   - `connect-src 'none'` を指定し、万が一の悪意あるスクリプトや拡張機能の混入時にもブラウザレベルで外部へのデータ送信を強制遮断。
3. **ゼロ・トラッキング / 最小依存**:
   - Google Analytics や外部トラッキングタグ、外部CDNスクリプトは排除。
4. **クリップボード自動消去（オプション）**:
   - コピー後30〜60秒経過でクリップボードを自動クリアし、履歴残存リスクを低減。
5. **マスキング機能**:
   - 周囲からの覗き見（ショルダーハック）を防ぐためのワンタップ表示/非表示トグル。

## 📋 機能要件

### 1. コア機能
- **即時生成（0秒生成）**:
  - アプリを開いた瞬間にデフォルト設定（例: 英大文字・小文字・数字・記号混在、16文字）で1件生成済み。
- **ワンタップ生成 & ワンタップコピー**:
  - 再生成ボタンで瞬時に新しいパスワードを生成。
  - コピーボタンタップでクリップボードへ保存し、視覚的なトースト（フィードバック）を表示。
- **柔軟なカスタマイズ**:
  - 長さスライダー / 数値入力（デフォルト16文字、範囲: 4〜64文字）
  - 文字種トグル: 英大文字 (`A-Z`)、英小文字 (`a-z`)、数字 (`0-9`)、記号 (`!@#$%^&*...`)
  - 紛らわしい文字の除外トグル（`0` / `O` / `o`、`1` / `l` / `I` 等）
  - 記号セットのカスタマイズ（サービスによって使える記号が制限されている場合への対応）
- **プリセットモード（ワンタップ切替）**:
  - 🔒 **強固（推奨）**: 16〜20文字 / 全種混在
  - 🏢 **社内・レガシー用**: 12文字 / 記号限定（一部記号不可サービス対応）
  - 🔢 **PINコード**: 4〜8桁 / 数字のみ
  - 🗣️ **パスフレーズ風**: 覚えやすい単語組み合わせモード（将来構想）

### 2. PWA & UX要件
- **PWA対応**:
  - Web App Manifest / Service Worker
  - スマホ（iOS Safari / Android Chrome）およびPCで「ホーム画面に追加 / インストール」可能。
  - スタンドアロン表示（URLバー非表示）でネイティブアプリ同様の快適な体験。
- **モバイルファーストUI**:
  - 片手で親指操作しやすいボタン配置。
  - ダークモード対応（システム設定連動 / 手動切替）。

## 🛠️ 推奨技術スタック

- **フロントエンド**: Vite + React + TypeScript + Tailwind CSS（または軽量Vanilla HTML/JS）
- **PWA**: `vite-plugin-pwa`（Workbox による完全オフラインキャッシュ）
- **ホスティング**: Cloudflare Pages（GitHub push連動の自動ビルド＆無料エッジ配信）
